# 10 Communication and Collaboration

## Tools Used
- **Discord**: For day-to-day communication.
- **GitHub**: For code sharing, version control, and tracking progress.
- **Teldraw**: For sketching out architectural ideas, UI layouts, and grid representations.

## Methodology
The team used a highly collaborative, shared problem-solving approach.
- **Constructive Design Disagreements**: When Yrziqi implemented a visual solution that Amelhach questioned, they would discuss alternatives until a consensus was reached. This was treated as normal design iteration, not conflict.
- **Unblocking Each Other**: When one teammate was stuck, they explained the problem to the other. Often, simply vocalizing the problem (rubber ducking) or discussing it led to the solution.

We did not use formal Agile ceremonies (no scrums or sprints), but relied on *continuous feedback* and *iterative development*.
