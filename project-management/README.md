# Pac-Man Project Management Documentation

## Purpose
This directory contains the professional project management documentation for the Pac-Man school project developed by Amelhach and Yrziqi. It provides an evidence-based overview of how the project was managed, structured, and executed.

## Project Summary
We developed a complete and polished Pac-Man clone extending beyond the minimum requirements. Built with Python and MLX, the project incorporates additional mechanics, sounds, and custom UI/UX elements. 
An officially packaged and playable release is available at: [https://amine-elh.itch.io/pacman-binary](https://amine-elh.itch.io/pacman-binary)

## Team
- **Amelhach**: Backend, game logic, gameplay systems, sounds effects,technical infrastructure
- **Yrziqi**: Frontend, UI, visualisation, UX, configuration and presentation systems
